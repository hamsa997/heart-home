# **App Name**: PetMatch Connect

## Core Features:

- Pet Listing & Search: Browse available pets with filtering options by species, age, and location. Each listing displays a main photo and key information.
- Pet Profile Pages: Dedicated pages for each pet, featuring multiple photos, a detailed description, personality traits, and adoption requirements.
- Adoption Inquiry Form: A streamlined form for prospective adopters to submit their interest and basic contact information for a specific pet.
- Admin Pet Management: An administrative interface for authorized users to add new pets, edit existing pet details, update their availability status, and upload images.
- Admin Application Review: An administrative dashboard to view, filter, and manage adoption inquiry submissions, including updating their processing status.
- AI-Powered Pet Description Tool: A generative AI tool for administrators to assist in crafting engaging and informative pet descriptions based on a few input prompts about the pet's characteristics and story.

## Style Guidelines:

- Primary color: A friendly and trustworthy blue-gray (#2E8AB8) to represent calm and care in pet adoption.
- Background color: A very light, almost white, desaturated blue-gray (#F0F3F3) that is visibly of the same hue as the primary color, providing a clean and inviting canvas.
- Accent color: A vibrant greenish-cyan (#2EC1A9) for calls to action and highlights, analogous to the primary color, providing energy and clarity.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, slightly technical yet approachable feel in titles and headings.
- Body font: 'Inter' (sans-serif) for body text, ensuring excellent readability and a clean, neutral presentation across various content types.
- Utilize simple, line-art style icons with rounded edges, depicting various pets, common actions (e.g., 'apply'), and navigation elements to maintain a friendly and cohesive visual language.
- A responsive, grid-based layout prioritizing clear, spacious cards for pet listings with prominent images, ensuring a delightful browsing experience on all device sizes. Information on pet profile pages will be well-structured for easy digestion.
- Implement subtle, smooth transitions and micro-interactions, such as fading on image loads and gentle button hovers, to enhance user engagement without distracting from the primary content.
